## Issues Fixed

### 1. JSONB Serialization Bug
**Problem:** `AttributeError: 'dict' object has no attribute 'encode'`

**Root Cause:** Pydantic's `model_dump()` returns Python dictionaries, but asyncpg expects JSON strings for JSONB columns.

**Fix Applied:** Added `json.dumps()` conversion in `patterns.py`:
```python
"target_base_color_sci": json.dumps(pattern.target_base_color_sci.model_dump()) if pattern.target_base_color_sci else None,
"target_base_color_sce": json.dumps(pattern.target_base_color_sce.model_dump()) if pattern.target_base_color_sce else None,
```

### 2. Row Mapping Bug
**Problem:** `ValueError: dictionary update sequence element #0 has length 36; 2 is required`

**Root Cause:** `dict(row)` doesn't work with SQLAlchemy text() query results.

**Fix Applied:** Changed to proper mapping:
```python
{key: getattr(row, key) for key in row._mapping.keys()}
```

### 3. Schema Validation Bugs
**Problem:** Missing required fields in payloads

**Root Cause:** Schema definitions didn't match API expectations.

**Fixes Applied:**
- Added `round_number` field to `RoundCreate` schema
- Added `sample_number` field to `SampleCreate` schema  
- Added `source_sample_id`, `source_layer_number`, `target_layer_number` to `CopyLayerRequest` schema
